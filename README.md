# Revelação

Um jogo de terror de tensão no navegador. Você é o revelador de fotos da Foto Íris, em São Paulo, 1957, e uma figura começa a aparecer nas suas fotos, cada vez mais perto.

Em desenvolvimento. Veja o [roadmap](docs/ROADMAP.md).

## Rodar local

```bash
cd web
npm ci
npm run dev
```

## Stack

- **Jogo:** React, TypeScript, Three.js (React Three Fiber), shaders GLSL, Tone.js. Site estático na Vercel.
- **Ferramenta das fotos:** CLI em Go que confere e prepara as camadas de cada foto.
